# 服务商账号注册助手（Agent Skill）

一个给 AI 助手用的 Skill：替用户跑服务商网页注册流程时，先确认账号是个人还是企业上下文，逐项核对身份字段，不编造公司信息、不代设密码，遇到只有用户能过的步骤（绑卡、验证码、条款确认）就干净停下并交回。

## 里面有什么

- `SKILL.md` —— 完整方法：确认上下文 → 只填用户给过的字段 → 卡住就停 → 先办账号再谈权益
- `skill.yaml` —— Skill 元信息

## 适用对象

- 用 AI 助手代办云厂商 / 开发者平台 / 支付渠道账号注册的开发者
- 关心"助手别替我编资料、别动我密码"的用户

## 怎么用

把本目录作为 Skill 包导入你的 AI 编程助手（CodeArts 或其他支持 Skill 的 Agent 环境），下次让助手办账号注册时，它会按这套检查清单执行。

## 背景

2026 年 10 月的两次真实踩坑沉淀：

1. 助手在一次企业账号注册中自作主张填了个人邮箱，被用户当场纠正 —— 从此"身份字段绑定上下文，动手前先问"。
2. 另一次注册卡在服务商邮箱验证的服务端报错（多个入口反复失败）—— 正确做法不是硬试，而是停下，把官方注册链接交回给用户。

与其让每个用户都付一次学费，不如把教训写成 Skill。
